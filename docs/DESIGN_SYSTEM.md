# 设计与交互规范

## 视觉系统
主题：冬日校园邮局。采用纸本档案、双色印刷、邮戳与原创剪纸，适合大学校园公共触摸屏。

| 用途 | 采用值 |
| --- | --- |
| 底纸 | #f4efdf |
| 明信片纸 | #fffaf0 |
| 墨绿正文 | #263e32 |
| 朱红行动按钮 | #cf402d |
| 原创插画 | 薄荷、陶土、麦黄、灰蓝 |
| 中文 | Microsoft YaHei / PingFang SC / sans-serif |
| 英文刊头 | Georgia / serif |
| 主要操作 | 60–82px 高，关键触摸区域至少48px |
| 页面动画 | 400ms 轻微纸页进入 |
| 明信片翻面 | 650ms 透视翻面 |
| 选择反馈 | 500ms 印章落下 |

无官方 Logo，无学校品牌色声明，无外部字体/CDN依赖。插画构图为想象的校园风景，不代表任何学校真实建筑。减少动态效果开启时禁用动画和过渡。

## 五屏职责与流程
P0：大明信片主视觉与探索入口。P1：学校筛选+内部滚动的海报墙。P2：活动资料与明信片入口。P3：自动匹配正反面、点击或键盘翻面、确认。P4：已选活动、对应明信片与数字收藏印章。

P0 → P1 → P2 → P3 → P4 → 清空 → P0。P3可回P2，P2可回P1。顶部品牌按钮随时重置。

- 一次会话最多确认一个活动；确认后只展示当前结果，返回首页开启下一次。
- 列表返回保留学校筛选与实际点击时的滚动位置；切换筛选归零。
- 明信片由 postcardId 和 eventId 同时匹配，不允许错配或无卡确认。
- 活动数量为零显示空状态；无卡显示说明和返回入口。
- 确认保存 eventId、postcardId，在当前内存展示；不写入长期存储。
- 90秒无 pointerdown、keydown、wheel 操作后显示15秒倒计时；继续探索/背景操作取消，超时或立即结束清空。
- 刷新回P0，筛选、翻面、选择结果均不恢复。
- 页面切换将焦点放在标题；对话框焦点进入“继续探索”，Tab循环、Escape继续并恢复焦点。

## 视口
横屏1920×1080、1366×768：固定头尾，列表内部滚动；P3根据剩余高度缩放，保留完整确认栏。窄屏改为单列与页面滚动，属于辅助适配。

主题色和时间入口在 data.ts，实际布局样式在 style.css。当前不提供主题切换功能；正式主题替换需同步插画与样式，不宣称仅改配置即可完整换肤。
