## 2. E2E 功能覆盖范围

- **HOME 总入口**：首屏渲染、普通访客默认隐藏演示控制台、四径跳转、静音切换。
- **路线 A（屏幕探索）**：拆信 → 三校中文筛选 → 活动信纸详情 → 真实三校 A6 明信片 3D 正反翻面 → 实色收藏套盖章 → 完成页转 C / 转 D 衔接。
- **路线 B（秋千停留）**：可用、占用中、已关闭三种状态切换与指引验证。
- **路线 C（实体领卡）**：01–07 完整正常流程（秋千与实体按键触发、枝端灯、叶形卡飘落、侧盘取卡灯、确认取走复位）+ 异常分支（雨风暂停验证不阻断 A/B/D、卡滞停机不自动补发）。
- **路线 D（时光邮局）**：开放态 7 款选卡 → 实时背面排版填写 → 专用封袋核对与盖章仪式 → 数字演示回执；关闭态切换与自留卡翻阅。
- **无操作超时机制**：`?idle=900` 触发 15 秒倒计时弹窗并验证「继续当前体验」安全恢复。

## 3. 视觉审查发现与迭代修复记录

在首轮真机截图审查中主动发现并彻底修复了 5 项视觉与交互问题，随后全量重测复核通过：

1. **演示控制台按钮遮挡**：初版位于右下角遮挡路线 D 选卡主按钮 → 调整至底栏正中胶囊位，全站零遮挡。
2. **主按钮文字对比度**：全局按钮继承样式优先级高于 `.v6-btn-primary` / `.v6-btn-accent` → 改为 `:where(.v6-root)` 零优先级声明，全部主按钮恢复高对比米白文字。
3. **路线 A 信封口袋花砖拉伸**：`.v6a-pocket > svg` 误命中底部花砖 SVG → 精确限定为 `:first-child`，恢复干净纸袋与底边花砖带。
4. **HOME 树枝与主标题重叠**：初版左上树枝穿过「拾一片花叶」标题 → 重排树冠至上中留白区并调整悬叶位置，文字 100% 清晰无遮挡。
5. **路线 C 落盘叶形卡遮挡托盘文字**：初版叶形卡落点居中盖住取卡提示 → 托盘右侧预留 128px 落卡槽，提示文字与叶形卡清晰并列。
