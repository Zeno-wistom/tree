## 可替换假设
- 中文单语言，横屏 16:9，1920×1080 / 1366×768 验收，同时提供窄屏布局。
- 冬日节庆主题为演示，不宣称正式节日活动；学校名称为筛选信息，颜色为作品配色，不是学校官方品牌色。
- 全部活动/日期/地点/文案均为明确标注的演示，插画为原创 SVG，不使用伪造 Logo。
- 无后端、无账号、无硬件；选择只存当前内存，刷新回到首页。
- 默认 90 秒无操作提示，15 秒重置，可通过独立配置调整。
