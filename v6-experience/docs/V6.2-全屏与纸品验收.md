## 实现

- **一棵树、四条路线**。`App.tsx` 删除全局等比舞台，满屏纸底、树影和花砖持续存在。首页入口、标题、筛选与操作按钮按真实视口布局。只为信封内部及 C 装置内部使用自己的等比坐标，由 `useObjectScale.ts` 随各自容器大小更新。首页和 A 保持同一只信封。
- **开信**。`ExploreRoute.tsx` 同步处理封口、封盖、信封和卡片，时间轴的关键起点分别为 0.00、0.07、0.10、0.43 秒。翻盖越过 90° 时从前片上方移到卡片后方。风和指针影响叶封内层，开信用外层完成掀起和移开。返回时反播当前进度。
- **收藏**。阅读时信封退至纸张左下方。收藏时把同一张卡带回封口上方，在卡面落印，再沿开口移入。卡片层夹在信封内衬和 SVG 前片之间，遮挡由前片实体形状产生。回首页复用同一前片和封盖。
- **B/C**。`GardenBackdrop.tsx` 定义共用的版画枝叶和秋千，B 保留三态与安全提示。C 重绘枝端、独立预告灯、按键位置和侧盘。按原 01–07 推进，在预告后、离枝前再次检查放行；正常模拟叶卡沿连续曲线到达侧盘，异常保持原分流。四季展示用实际卡片，领取按供应配置及替代卡确认。在访客模式下，操作模拟边界持续可见。
- **D**。沿用选卡、日期、方式、核对、封袋和回执。A 可带已收藏或正在阅读的三校卡进入 D，首页入口独立选卡。只使用演示交接信息。

## 资料与依赖

- 读取本机 `Dezhi_Interaction_Leaf_Drop.pdf` 原件（1 页，页名「德智广场 / 拾花一叶 · 交互全流程」）。本机副本文件名无「(1)」。核对了 A/B/C/D、C 七阶段、五类异常及模拟边界。
- 从仓库「新素材」源稿核对三校 A6 画板和四季异形三角梅叶卡。保留原图案和标识，并沿用正式海报式四季卡、原澳门花砖纹样与本地字体。[素材映射](ASSET_MAP.md)
- 重新绘制设备场景、枝纹、叶脉、秋千与按键，重新组织信封和盖章的纸张层级。使用本工程 SVG、CSS 和 GSAP。采用既有 `gsap@3.15.1`、`@gsap/react@2.1.2`；MotionPathPlugin 来自既有 GSAP 包，无新增 npm 依赖或第三方复制组件。[GSAP Standard License](https://gsap.com/community/standard-license/) · [GSAP MotionPath](https://gsap.com/docs/v3/Plugins/MotionPathPlugin/)
- 设计方向按用户确认的现代植物版画与交互式纸本艺术执行。Huashu Design、Vibe-Upgrader 用于审视布局、反馈和实图，按任务授权直接在独立工作树逐步集成，最终截图和录屏供用户判断实际视觉效果。

## 测试结果

- 生产构建通过，单元测试 4/4，Playwright Chromium 26/26。[E2E 报告](v6.2-rebuild/e2e-results.json)
- 1920×1080、1366×768 运行完整回归，两种尺寸各进行了五次触控模拟开信和中途反播。1600×900、1440×900 增补四路线可达性、全屏容器与按钮边界、阅读无遮挡、收藏前片遮挡、按键领卡及带卡进入 D 检查。
- [录屏运行记录](v6.2-rebuild/recording-observations.json) 显示三次正常动效录制中无浏览器报错、警告或资源失败。另以解码帧检查开信与中途返回、盖章与藏入、预告与落盘。[解码时间点](v6.2-rebuild/playback-review.json)
- 在真实 Chromium 中使用鼠标和模拟触控。现场公共触摸屏、实体秋千传感、发卡装置、实际邮寄与支付未联调。Safari、Firefox 和手机竖屏未验收。
