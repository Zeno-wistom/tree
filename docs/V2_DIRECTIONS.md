# 校园来信 V2 · 视觉方向评审

## 本轮边界

- V1 保留原首页、数据与五页流程；`codex/v1-baseline` 是本地保留分支，`codex/v2-directions` 制作对比原型。
- 本阶段只交付 A/B/C 的首页与活动发现页、筛选反馈与代表动效。活动可查看资料，但不开放确认选择。
- 同一 V1 六条演示活动、学校信息、日期、地点与演示声明；不增加真实校园事实或硬件功能。
- 目标 1920×1080 / 1366×768 横屏，兼顾窄屏；待用户选定后才统一改造全部五页。

## 产品事实与共同骨架

公共空间的短会话触摸屏；访客发现活动、查看资料、预览数字明信片。首页主角是校园场景与开始探索，发现页主角是活动和学校筛选。不设搜索、登录、支付与硬件控制。真实素材未知，采用原创 SVG 插画，建筑与人物不指代真实个人或校舍。

共同调性：亲和、趣味、成熟；中等偏活泼的能量，手绘/材质细节而非锐利编辑排版，较疏的信息密度，轻盈而有触感。主动作始终清晰，控件大于 48px。图片为视觉材料，不伪造学校官方品牌。

## A · 柔软的校园互动绘本

- 北极星：翻开一本会回应你的校园绘本。
- 结构：大幅曲面手绘场景占据右侧并环抱标题；发现页是摊开的跨页长卷，活动像书页中的图鉴，不是规则卡片墙。
- 字体/颜色：圆润中文黑体、奶油白与草木绿、杏桃粉；原创手绘感人物、树与校舍。
- 交互：翻页入场、叶片轻呼吸；筛选时书页展开，活动图鉴依次出现。记忆点是“翻开一页，走进校园”。

## B · 具有玩具感的互动邮局

- 北极星：每张校园明信片，都从一座快乐邮局出发。
- 结构：首页是一座可触摸的玩具邮亭与投递口；发现页为邮品陈列窗口，活动像不同面值的邮票。
- 字体/颜色：粗圆标题、奶油黄、番茄红与亮湖蓝；玩具漆木与软塑料质感，圆角和实体按键阴影。
- 交互：邮亭部件依次落位，投递口轻轻开合；筛选是拨动邮局分类钮，邮票滑入收集托盘。记忆点是“盖一下，取出一张”。

## C · 具有探索趣味的校园奇遇空间

- 北极星：沿着一条会生长的路，找到校园里的新鲜事。
- 结构：标题环绕一幅校园微缩漫游图；发现页是连续的探索地图，活动分布在小径节点，路线而非网格建立阅读顺序。
- 字体/颜色：有生命力的标题、嫩叶绿、天空蓝与日光橙；手绘地图、可探索植物与不规则路牌。
- 交互：路线展开、路牌竖起、树叶出现；筛选时对应节点亮起，其他节点退到背景。记忆点是“让下一场相遇亮起来”。

## 动效门槛与技术决定

- 首次入场用于解释空间关系；待机只保留少量低频装饰，阅读信息与按钮不持续移动。
- 筛选是高频操作，以短促的空间/状态反馈为主，不做持续弹跳。
- GSAP Timeline 编排主角入场；`useGSAP` + scope + contextSafe + cleanup，matchMedia 处理 reduced-motion。不使用 ScrollTrigger。
- 只动画 transform / opacity；动画不阻塞业务状态，触摸/鼠标/键盘均能操作。

## Oil UI 过程记录

已读取并应用 `oil-ui` 主流程、显式探索、设计方向、视觉语言、动效、素材、工作区和工具规范。按用户已明确批准的要求制作可运行的首页和发现页，覆盖其工具说明中静态首屏的默认路径。现有 V1 截图作为现状参考；本轮没有新增外部产品参考，不宣称做过标杆拆解。当前执行约束不使用子 Agent，因此方向生成、适配把关和视觉评审均为主 Agent 自检，不是独立评审。

过程文件在 `.oil-ui/v2-directions`，正式页面在 `src/v2`，正式证据在 `docs/v2`。不使用 Oil UI 生图积分、不消费付费服务。其安装器报告 2 条 Socket 风险提醒，实际调用仅版本检查、对比页生成器与独立 Edge 截图/录屏工具；截图工具使用临时浏览器和本机临时服务，未访问用户个人浏览器资料。
