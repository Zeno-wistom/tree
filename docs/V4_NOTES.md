## 1. 对 V3 的真实审计（先跑，再改）

审计脚本：`docs/audit-v3/audit.mjs`，产物在 `docs/audit-v3/`。
浏览器实测（Edge / Playwright，1920×1080 与 1366×768），控制台无报错。

| # | 现象 | 归类 | 真实原因 |
|---|------|------|----------|
| 1 | 首屏先出现整屏米色 + 左上角「校园来信正在准备…」，约 700ms 后整页突然出现 | 时序错误 | `main.tsx` 里 `React.lazy` + `Suspense fallback`；`index.html` 只有一个空 `#root`，没有任何静态首帧。实测 200/400ms 两帧只有一行文字（`docs/audit-v3/first-0400ms.jpg`）。 |
| 2 | 待机几乎看不到风 | 表现力不足 | 风带与叶子写在信封**背后**的图层（z-index 低于信封），而信封占满画面中部，元素实际被完全遮挡；同时 `.leaf` 终态 `autoAlpha:0`，两次阵风之间几乎是空档。 |
| 3 | 风没有吹起封条 | 实现缺失 + 表现力不足 | 封条只有 `rotationX:-28` 的轻微旋转，且元素是实心红条、没有阴影/受光变化；信封本身不参与受力，缺少因果关系。 |
| 4 | 开封过程有大段空屏、元素贴边裁切 | 时序错误 | 信封被 `y:505 / rotationX:47 / scale:.78` 推到画面外，560ms 时屏幕上几乎没有主体；随后卡片从视口下缘硬切入。 |
| 5 | 多处「淡入淡出 + 突然跳位」 | 时序错误 | `useGSAP(..., { revertOnUpdate: true })` 每次 phase 变化都会回滚上一段 timeline 写入的内联样式，再重新 set，导致位置回跳。 |
| 6 | 扇形排列不可读、卡片互相遮挡标题 | 视觉设计 | 6 张 300px 宽卡片以 183px 间距排布（39% 重叠），标题落在被相邻卡片覆盖的区域。 |
| 7 | 详情 / 明信片 / 完成页像是另一套设计 | 视觉设计 | 详情是圆角白面板，明信片背面没有纸张底色（翻转后透出正面插画），完成页的 sleeve 与卡片互相压叠、文案叠在信纸上。 |
| 8 | 整体「SVG 拼贴感」 | 视觉设计 | 折纸结构只有两条斜色块、无厚度、无折痕阴影；字体为系统雅黑；印刷细节（邮票/邮戳/地址）缺失或不可辨。 |

## 2. 重构后的实现要点

### 2.1 首帧（最高优先级）
- `index.html` 内置**完整静态信封首帧**（masthead + 信封 + 印刷细节 + 版权行），样式通过 `<link rel="stylesheet">` 直接引用与 React 共用的 `base.css` / `scene.css`，**不依赖任何 JS**。
- `--stage-scale` 由 `<head>` 内联脚本在首次绘制前算好，静态首帧与 React 舞台共用同一套 1440×810 坐标，几何完全一致。
- React 挂载后连续两次 `requestAnimationFrame` 再把静态层淡出并移除；实测静态层与 React 待机态的**平均像素差 0.12/255，差异像素 0.22%**（`docs/v4/diff2.mjs`，`diff-shell.jpg` / `diff-app.jpg`）。
- JS 被完全阻断时仍显示完整信封（`shots/firstframe-nojs.jpg`、`prod-shell.jpg`）。
- 静态层上的首次点击会被记录为「想开信」，React 接管后立即执行，不会出现点了没反应。

### 2.2 风 · 叶子 · 封条
- 风的进入是**逐帧随机**的：每次阵风用 `gsap.timeline` 现建，方向左右随机、强度 0.72–1.22 随机，间隔 4.4–8.2s，所以不会看出循环。
- 3 条带渐变的曲线气流（一条在信封后，两条在前），配合 3 片不同深度/速度/旋转量的叶子（前层 2 片、后层 1 片），叶片有落地前的减速与自旋。
- 封条是**纸带 + 红色圆形印**：下段以顶端为轴 `rotateX` 抬起、轻微 `rotateZ`、出现下缘受光边与投影；阵风同时让整只信封轻微侧倾 0.55° 并回弹，形成「风 → 信封受力 → 封条翘起」的因果链。
- 待机弱提示「轻轻一按，替你拆信」随阵风呼吸，不做弹窗。

### 2.3 大信封
- 折纸结构：上盖三角 + 侧翼 + 底翼，折痕用 SVG 渐变描边与三层柔化阴影表现，盖沿投影用 SVG 模糊路径（不用 CSS filter，规避 3D 合成问题）。
- 纸张：双层渐变 + 颗粒（`public/v4/grain.svg`）+ 边缘高光/内阴影 + 纸张厚度层（`.env-stack`）+ 接触阴影。
- 印刷：封面标题用字重圆润的站酷快乐体（本地 woff2，子集 51KB）；地址块、PAR AVION、邮票（带齿孔与图幅）、邮戳（弧形文字 + 注销波纹）、以及德志广场的丝网印风景（榕树、回廊、葡式波浪石纹地面）都是「印在纸上」的元素，跟随物体一起运动。
- 字体：`Campus Display`（站酷快乐体，标题）、`Campus Text`（Noto Serif SC 子集 176KB，正文）、`Campus Serif`（Instrument Serif，数字与拉丁小标）。

### 2.4 开封
Timeline（`open()`）：封条被完全掀起 → 脱离封口 → 封盖围绕顶部折轴翻起（-62° → -168°，两段缓动）→ 镜头推近（scale 1.05）→ 内部纸叠上浮 → 镜头越过信封上沿（scale 2 / y 548），信封前壁成为舞台 → 6 封活动信从口袋里升起。
- 卡片始终在信封**之后**（z-index），靠前壁遮挡实现「从信封里出来」，没有用淡入淡出伪造。
- 跳过按钮调用 `progress(1)`，状态与自然播完一致。
- 快速连点由 `busy` 闸门 + `tl.kill()` 处理；实测连点 3 次 + 强制点击后仍稳定停在 DISCOVER。

### 2.5 活动信封
- 6 张 264×360 的纸质信封卡，间距 212、旋转 ±3.3°、垂直微弧，卡片底部被前壁遮住，形成「插在口袋里」的群体感。
- 鼠标悬停：当前卡抬起 44px、放大 1.055、投影加深、显示「打开这封来信」，相邻卡各让位 15px；指针移动只对当前卡做 `quickTo` 视差（写在 `.card-tilt` 内层，不冲突）。
- 触摸：首点聚焦（`is-focus` + 托盘文案联动），二点打开。
- 筛选：旧卡下沉收走 → 换组 → 新卡从口袋升起（`useEffect([school,batch])` 重排）。

### 2.6 后四页
- 详情：选中卡开盖 → 信纸由卡片尺寸（scale 0.281）连续长成整张信纸，返回时反向缩回卡片，空间连续；信纸有信头、事实栏、正文、手写收束句、邮戳。
- 明信片：信纸退后、明信片从底部升起；卡片有纸张底色、厚度边、印刷内框、投影；翻面为 3D `rotateY` + 抬起 + 阴影变化，连续翻转后仍停在完整一面。
- 完成：卡片左移缩入半透明封套（封套在卡片之上，玻璃纸质感），「已收藏」印章落下并压印、印圈扩散，右侧文案与进度条收尾。

### 2.7 工程
- 舞台缩放改用 `zoom` 而非 `transform: scale()`：既避免缩放导致的栅格化模糊，也绕开了「多个 3D 变换层叠加时 Chromium 把裁切区渲染成黑色」的合成缺陷（本轮最耗时的坑，见下）。
- **只保留一个信封图层**（`.env-layer`）。原先 back/front 两层各自 3D 变换并叠加时，Chromium 会把前层未覆盖区域渲染为不透明黑色（`docs/v4/shots/test-merged.jpg` 前后对比）。合并后口袋、前壁、封盖、封条在同一层内用 z-index 排布，遮挡关系反而更真实。
- 所有过渡显式 `fromTo`，不再使用 `revertOnUpdate`；页面切换前 `tl.kill()`，避免样式回滚跳位。
- `pointermove` 只作用于当前聚焦卡的 `.card-tilt`，用 `gsap.quickTo`。
- `visibilitychange` 暂停 GSAP 全局时间轴；`prefers-reduced-motion` 下环境动画不启动、过渡时长压到 0.001s。
- 尺寸变化只改 `--stage-scale`，舞台内部全部是常量坐标，不需要重新测量。

## 4. 仍未达到预期的地方

1. **390px 竖屏**只是把 16:9 舞台按宽度缩放居中，信封偏小；没有做真正的竖屏重排。桌面/横屏是本轮的设计目标。
2. **邮票与邮戳**在 1366 下字号接近 6–7px，只能作为质感纹理，不可逐字阅读。
3. **明信片正面插画**是几何丝网印风格，六张之间靠色相与图形区分，细节密度低于封面主视觉。
4. **封条翘起**在 1920 下可读，但幅度受封条本身尺寸限制，仍不如真实纸张夸张；进一步放大需要重排地址块。
5. **字体子集**按当前界面文案生成（`scripts/make-fonts.py`），新增文案若含未收录汉字会回退到系统字体。
6. `?idle=` 是为自动化验收加的调试参数，正式交付可移除。
