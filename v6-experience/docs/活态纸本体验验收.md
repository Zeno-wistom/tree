# 《拾花一叶》活态植物纸本体验

从 `codex/v6.1-experience` 的 `v6-experience/` 开发，基线提交为 `543581b`。本地访客入口为 [127.0.0.1:5198](http://127.0.0.1:5198/)，评审可用 [演示入口](http://127.0.0.1:5198/?demo=1)。时令可由入口参数 `?season=spring|summer|autumn|winter` 指定，C 路线在演示入口也可切换。

## 相比 V6.1

- **首页**以树枝、飘落花瓣、花砖和斑驳光影围合大信封。轻触叶封后，同一只信封放大、下沉、揭封并抽出三校真卡。按途中返回可撤回开信，A 中的返回也会收起或退回纸品。
- **A**把活动信息排在正式明信片背面的书写区，保留院校筛选和分页。选卡后同一张纸放大；触碰翻见花卉原稿。收藏经历入套、邮戳触纸和落印，会话结束后清空。
- **B**以树荫中的秋千和摆动回落提示停留安全。**C**在同一画景中呈现枝端预告灯、秋千、空地和侧盘，四季叶卡全部可预览。正常取卡经受理、触发、停稳确认、分阶段预告与确认落盘。异常切换和工作人员复位收纳到演示入口的小抽屉。
- **D**保留拖动换卡、背面落笔、澳门日期选项、模拟交接方式、核对、封袋盖章及回执。使用固定示例收件人和虚构交接地点，寄语在退出路线时清空。邮局暂停时仍可翻阅自留卡和体验模拟寄送。
- **动效**复用 `GSAP` 与 `@gsap/react`。独立元素分别承载移位、倾斜和翻面。目标浏览器支持 View Transition 时让 B/C/D 与树下场景轻柔衔接。无该能力时使用 CSS 淡入；减少动态效果模式下关闭飘动和场景交叠。
