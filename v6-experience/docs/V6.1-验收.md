## 检查结果

- `npm run build` 通过 TypeScript 检查与 Vite 生产构建。
- `npm test` 通过原有 4 项单测。
- `npm run test:e2e -- --workers=3` 通过 18 项，两个尺寸各 9 项。原有 12 项跨尺寸业务检查保留。C 路线在测试中从树下场景重新进入，以匹配新版入口。[Playwright 结果](e2e-results.json)
- 触摸模拟下，每种尺寸连续开信 5 次。逐帧检查同一个信封节点、按压、揭签、翻盖和抽信，并验证开到一半退回、闭合复位及再次打开。
- 普通 C 路线通过预告灯、叶片飞行、侧盘中心落点与取卡检查。演示模式覆盖受理失败、未停稳、出卡异常、飞偏和遗留五类，以及替代卡和恢复操作。
- 两种尺寸分别实测鼠标磁吸、D 拖动换卡、翻面、直接在卡背落笔、装袋盖章与回执。另以减少动态效果和 Chromium 触摸模拟验证 D 的轻触翻面与滑动换卡。录屏流程无浏览器错误或警告，页面无整体溢出。
- 实体触摸屏、硬件联动和真实邮寄尚未实地验证。C 发卡与 D 寄送仍为网页原型。
