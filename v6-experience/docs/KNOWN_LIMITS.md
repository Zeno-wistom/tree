# 《拾花一叶》V6 已知限制与演示边界说明

1. **硬件与传感器边界**：秋千感测、停稳联锁、机械发卡出卡、枝端/侧盘物理灯光控制均未接入真实硬件，界面均以明确标注的「演示状态 / 硬件演示模拟」呈现，可通过 `?demo=1` 控制台切换各种现场状态进行评审演示。
2. **时光邮局与数据存储边界**：时光邮局未接入真实邮寄、支付或后端数据库，生成的数字回执仅存在于当前浏览器会话内存中，刷新或超时重置后自动清空。
3. **活动资讯边界**：路线 A 的 6 条三校活动继续沿用 V5 既有演示数据，并明确标注「演示活动 · 非官方资讯」。
4. **验证环境边界**：自动化与视觉验收基于无头 Chromium 在 `1920×1080` 与 `1366×768` 横屏视口完成；尚未在现场实体触摸屏硬件、高亮度户外反光环境或 Safari/Firefox 浏览器中做实测。
5. **仓库推送边界**：本地已在 `codex/v6-experience` 分支完整保存并保持原有 V5 文件零改动；因本环境不含个人 GitHub 写权限凭据，交付以独立 `v6-experience/` 目录与完整可下载压缩包形式提供，便于你在本地直接提交推送。
